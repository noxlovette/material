## Icons

`icons` controls the thumb icon: `checked` (the default) shows a check only when on, `both`
shows a check when on and a close icon when off, and `none` shows a plain thumb. Showing icons
gives a signal that doesn't depend on color alone.

<Canvas of={SwitchStories.IconModes} />

## Dragging

Besides click and tap, the thumb can be dragged: moving it more than 16px toward the other side
flips the state, like a native mobile switch.

```svelte
<Switch bind:checked={notifications} />
```

## Accessibility

- **Role.** The control is a `role="switch"` from bits-ui; Space and Enter toggle it.
- **Label.** The switch has no built-in label. Wrap it in a `<label>` with visible text, or give
  it an `aria-label`.
