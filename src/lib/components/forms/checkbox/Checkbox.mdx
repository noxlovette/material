## States

Bind `checked` for the value. Bind `indeterminate` for a "select all" checkbox whose list is
only partly selected; it wins over `checked` while set. `error` marks the control invalid.

```svelte
<Checkbox labelText="Accept terms and conditions" bind:checked={accepted} />
```

<Canvas of={CheckboxStories.States} />

## Accessibility

- **Label.** `labelText` is required and tied to the control by id, so clicking the text toggles
  the checkbox too.
- **Target size.** The state layer extends the target well past the 18dp box, to 48dp.
- **Keyboard.** Space toggles; focus draws the M3 focus indicator.
