## Showing a snackbar

There's no `toast()` function or queue. Mount one `Snackbar`, bind its `message`, and assign to
that state to show it:

```svelte
<script lang="ts">
  import { Snackbar } from '@noxlovette/material';

  let snackbarMessage = $state('');
</script>

<button onclick={() => (snackbarMessage = 'Changes saved.')}>Save</button>

<Snackbar bind:message={snackbarMessage} label="Undo" callback={undoSave} />
```

When `message` becomes non-empty (a string or a snippet), the snackbar slides in. After 4
seconds it hides and resets a string `message` to `''`, so the same text can be shown again. With
`static`, it stays until the user closes it.

`label` and `callback` add an action button.

## Accessibility

- **Timing.** A non-static snackbar disappears on its own, so never make it the only place
  critical information appears.
- **Dismiss.** `showClose` (on by default) renders a close button labelled "Dismiss snackbar".
- **One at a time.** Mount one snackbar per region and drive it through one binding; stacking
  instances isn't supported.
