## When to use it

M3 has no popover component; this one sits between its patterns. It opens on click and can hold
interactive content, unlike a `Tooltip`. It doesn't block the page and has no scrim, unlike a
`Dialogue`.

- **Popover:** supplementary information or a few controls tied to one button.
- **`Menu`:** a list of actions to choose from.
- **`Dialogue`:** anything that must be resolved before the user continues.

Pass the trigger as a snippet and spread the props it receives onto it:

```svelte
<Popover title="Storage">
  {#snippet trigger(triggerProps)}
    <Button variant="outlined" {...triggerProps}>Show info</Button>
  {/snippet}
  <Body>75% of your storage has been used.</Body>
</Popover>
```

## Accessibility

- **Dismissal.** Escape closes the popover and returns focus to the trigger.
- **Non-modal.** The rest of the page stays interactive while it's open, so don't use it for
  content that must block the user.
